## About UrbanCart

UrbanCart is a modern home lifestyle brand offering stylish, functional products for comfortable and organized living spaces. Our target customers are homeowners and renters aged 25–45 who appreciate quality design at affordable prices.

---

## Features Implemented

| Feature | Description |
|---------|-------------|
| **Homepage** | Store name, welcome message, and attractive layout representing the brand |
| **Product Page** | 5+ products with images, names, prices, and descriptions |
| **About Page** | Business description and mission statement |
| **Contact Page** | Email address, phone number, and working contact form |
| **Shopping Cart** | Add-to-cart functionality with checkout flow using offline/manual payment methods |

## Payment Method

The website uses **offline/manual payment methods** (Cash on Delivery and Bank Transfer) to demonstrate the full shopping cart and checkout experience without processing real payments.

---

## Challenges Faced

- Matching Wix template design to original Figma prototype
- Configuring shopping cart with offline payment options
- Ensuring responsive design across mobile and desktop

---

## Lessons Learned

- No-code platforms effectively bridge design and development
- Consistent UI/UX principles apply across all platforms
- E-commerce functionality can be implemented without coding knowledge
- Professional documentation enhances project presentation
